About This Project

🎯 Project Overview

This platform demonstrates the comparison between two reinforcement learning approaches for algorithmic trading: PPO (Risk-Neutral) and CVaR-PPO (Risk-Sensitive).

🤖 Models

1. PPO (Proximal Policy Optimization)

  • Risk-neutral baseline approach
  • Maximizes expected returns without explicit risk management
  • Actor-Critic architecture with 256 hidden units
  • Trained for 100 episodes on SPY data (2015-2022)

2. CVaR-PPO (Conditional Value at Risk PPO)

  • Risk-sensitive approach with CVaR constraint
  • Manages tail risk by penalizing worst 15% returns
  • Adaptive lambda parameter (0.16 → 0.10)
  • Focuses on downside protection and drawdown reduction

📊 Features

  • Real-time Prediction: Get live trading signals from both models
  • Backtest: Test model performance on custom date ranges
  • Model Comparison: Compare metrics side-by-side
  • Technical Indicators: SMA, RSI, MACD, Bollinger Bands, ATR

📈 Training Data

  • Symbol: SPY (S&P 500 ETF)
  • Period: 2015-01-01 to 2024-12-31 (10 years)
  • Split: 70% train / 15% validation / 15% test
  • Trading Days: 2,515 days total

⚙️ Configuration

  • Initial Balance: $10,000
  • Transaction Cost: 0.1% per trade
  • Slippage: 0.05%
  • Learning Rate: PPO: 3e-4, CVaR: 1.5e-4

🔬 Technology Stack

  • Backend: Python Flask
  • ML Framework: PyTorch
  • Data: yfinance, pandas, numpy
  • Technical Analysis: ta library
  • Visualization: Plotly, Chart.js

📝 Usage Notes

⚠️ Disclaimer: This is an educational project. Do not use these models for real trading without proper validation, risk management, and understanding of the limitations.

  • Models are trained on historical data and may not perform well in different market conditions
  • Past performance does not guarantee future results
  • Always implement proper risk management in live trading
  • Consider transaction costs, slippage, and market impact

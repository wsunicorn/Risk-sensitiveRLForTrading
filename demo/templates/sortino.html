Model Overview
Risk-Adjusted Sortino-PPO Approach

This model optimizes the Sortino ratio, focusing on downside volatility rather than total volatility. It provides better risk-adjusted returns by penalizing only negative returns below a target threshold, making it more suitable for risk-averse investors.

Sortino Ratio Focus:
  • Focuses on downside deviation only
  • Ignores upside volatility (good volatility)
  • Better risk-adjusted performance measure
  • Suitable for risk-averse strategies
  • Optimization: Sortino ratio maximization
  • Risk Measure: Downside deviation only
  • Target: Risk-adjusted returns
  • Advantage: Better than Sharpe for asymmetric returns
